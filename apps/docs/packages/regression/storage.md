## Directories

Regression records live under the application's `.stacknext` directory:

```text
.stacknext/
├── runs/         # run-<16 hex>.json
├── baselines/    # base-<16 hex>.json
└── comparisons/  # cmp-<16 hex>.json
```

The directory is created with mode `0700`; record files use mode `0600`.
`.stacknext/.gitignore` ignores runtime state, but saved records remain local
debugging artifacts and should be reviewed before sharing.

## API

```ts
import {
  saveRun,
  loadRun,
  listRuns,
  listAllRuns,
  saveBaseline,
  loadBaseline,
  listBaselines,
  saveComparison,
  loadComparison,
  listComparisons,
  regressionDir,
  runsDir,
  baselinesDir,
  comparisonsDir,
} from '@stacknext/regression'
```

Writes validate the full record with its versioned Zod schema before touching
disk. Writes are atomic. A record is never overwritten unless the caller passes
`overwrite: true`; the CLI only does that on an explicit `--overwrite` request.

## Listing

List functions return `{ items, total, limit, offset, invalid }`. `limit` is
clamped to 1–200 with a default of 50. Invalid ids and stale records are counted
in `invalid` and left visible; they are not repaired or silently deleted.

## Size and retention

- Each record is capped at 16 MiB.
- Runs, baselines and comparisons are **never pruned automatically**.
- StackNext never uploads records.
- `stacknext uninstall --remove-data` requires explicit confirmation and refuses
  while a StackNext process is running.

## Invalid records

`RegressionStorageError` carries a code used by callers to distinguish
`invalid`, `not-found`, `exists` and storage failures. Invalid ids are rejected
before the filesystem is read. A malformed file is counted, not rewritten.

## Privacy

Records contain redacted scenario identity, trace/span/query/error evidence,
diagnostic references, environment facts and a sanitized command snapshot.
They never contain request/response bodies, headers, cookies, URL query values,
SQL bind parameters, Playwright screenshots/video/trace archives or the
collector token. The full boundary is in
the repository `apps/docs/privacy.md`.
