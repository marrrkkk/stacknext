# StackNext public documentation

This directory is the Mintlify site for StackNext. It contains the public
product guides, the generated package reference, AI-agent integration pages and
the security/privacy overview.

```bash
pnpm docs:dev    # from the repository root
```

`docs.json` defines navigation, redirects and the model instructions that
Mintlify includes in AI-readable output. The site is deployed independently from
npm publishing.

## Mintlify deployment

The Mintlify project must have **docs.json is in a subdirectory** enabled with
the path `/apps/docs` in its Git settings. The repository root also contains the
engineering knowledge base under `docs/`, so the default root lookup cannot
find the site configuration. Without this setting the Mintlify GitHub App
reports `Unable to find docs.json` and does not publish previews or production
deployments. The setting is configured in the Mintlify dashboard, not in this
repository.

## Source of truth

- Hand-authored public pages live here.
- Package API reference is canonical in `packages/<package>/docs/`. The copies
  under `packages/<slug>/` and the CLI index are generated by
  `scripts/sync-docs.mjs`. Do not edit generated files.
- Contributor setup, testing, release, benchmark and architecture-decision
  documents live in the repository engineering knowledge base at
  [`../../docs/`](../../docs/README.md).

Run `pnpm check:docs` from the repository root after changing navigation, links,
package docs or generated copies. Mintlify generates `/llms.txt`,
`/llms-full.txt` and Markdown page variants automatically; do not commit them.
See [AI-readable documentation](ai-agents/llms-txt.md).
