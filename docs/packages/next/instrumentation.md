`register(options?)`

```ts
import { register } from '@stacknext/next'

await register()
```

Alias for `registerStackNext()`. Call it from the app's `instrumentation.ts`
`register()` hook. It returns `null` when tracing is disabled or another
provider is active.

## `registerStackNext(options?)`

```ts
import { registerStackNext } from '@stacknext/next'

const registration = await registerStackNext()
```

`StackNextRegisterOptions`:

| Option | Type | Meaning |
| --- | --- | --- |
| `transport` | `StackNextTransportOptions` | Overrides environment transport configuration. |
| `collectorUrl` | string | Collector URL, also used to filter self-instrumentation requests. |
| `serviceName` | string | OTel service name. Defaults to the transport value or `next-app`. |
| `projectName` | string | Project name reported to the collector. |
| `nextVersion` | string | Next.js version for the environment snapshot. |
| `captureFetch` | boolean | Set `false` to drop `AppRender.fetch` spans. |
| `enabled` | boolean | Set `false` to keep StackNext loaded but inactive. |

It returns a `StackNextRegistration` with `provider`, `transport`, `exporter`,
`serviceName` and `registeredAt`, or `null`.

### Registration order

1. Return the existing registration if this process already registered.
2. Return `null` when `enabled: false` or the runtime is not Node.js.
3. Return `null` when another OTel provider is already registered.
4. Resolve the shared transport from options or environment.
5. Return `null` when collector URL/token are absent.
6. Build a `NodeTracerProvider` with a `BatchSpanProcessor`:
   - scheduled delay 200 ms;
   - queue size 2,048;
   - export batch 256;
   - export timeout 2,000 ms.
7. Register the provider and install a composite W3C trace-context and baggage
   propagator.
8. Store the registration globally and hook `beforeExit` to flush.

The propagator is required so an incoming `traceparent` from a local Playwright
capture becomes the parent of the Next.js request trace.

## `getStackNextRegistration()`

Returns the active registration without creating one. Useful in tests and
shutdown code.

## `shutdownStackNext()`

```ts
import { shutdownStackNext } from '@stacknext/next'

await shutdownStackNext()
```

Flushes buffered spans and shuts down the provider and transport. Safe to call
more than once. Next.js owns process signals; StackNext only hooks
`beforeExit`.

## Manual exporter utilities

`StackNextSpanExporter`, `readableSpanToInput`, `spanAttributes` and
`StackNextSpanExporterOptions` are exported for tests and custom integrations.
`readableSpanToInput` returns `null` for invalid ids, internal instrumentation
spans and requests to the StackNext collector itself. It redacts names,
attributes, resource attributes and status messages.

## Self-instrumentation filter

Requests to `/__stacknext/` and the collector origin are excluded so the
dashboard and MCP traffic do not appear as application requests.

## What is not automatic

- Server Components are not traced individually.
- Server Actions are not named automatically. See [Custom spans](custom-spans.md).
- Application functions and arbitrary database drivers are not inferred.
- Browser/client tracing is out of scope.
- Edge runtime is not supported.
