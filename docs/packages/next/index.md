`@stacknext/next` connects a Next.js App Router application to a local
StackNext collector. It registers an OpenTelemetry `NodeTracerProvider`, converts
spans to the StackNext wire format, installs a W3C propagator, forwards
`onRequestError` hooks and exports optional manual span helpers.

## Who should read this

Application developers installing StackNext. This is a **public integration
package** and the only instrumentation package a normal project needs.

## Installation

```bash
pnpm add -D @stacknext/cli @stacknext/next
```

`@stacknext/next` declares `next >=15.0.0 <17` as a peer dependency. It requires
the Node.js runtime; the `edge` export exists only to keep Edge bundling safe and
returns an inert module.

## Quick start

`stacknext init` creates `instrumentation.ts` (or `.js`) that guards on
`NEXT_RUNTIME === 'nodejs'` and imports StackNext dynamically:

```ts
export async function register(): Promise<void> {
  if (process.env.NEXT_RUNTIME !== 'nodejs') return
  const stacknext = await import('@stacknext/next')
  await stacknext.register()
}

export async function onRequestError(
  error: unknown,
  request: unknown,
  context: unknown,
): Promise<void> {
  if (process.env.NEXT_RUNTIME !== 'nodejs') return
  const stacknext = await import('@stacknext/next')
  stacknext.onRequestError(
    error,
    request as Parameters<typeof stacknext.onRequestError>[1],
    context as Parameters<typeof stacknext.onRequestError>[2],
  )
}
```

Do not replace an existing `instrumentation.ts`. Import `registerStackNext` and
`onRequestError` into the existing hook instead. See
[Installation](installation.md).

## Behavior

- `register()` is inert when `STACKNEXT_COLLECTOR_URL` and `STACKNEXT_TOKEN` are
  absent. A production build can ship safely.
- If another OpenTelemetry tracer provider is already registered, StackNext
  yields to it and does not replace it.
- Spans are redacted and normalized before enqueueing.
- The exporter never performs synchronous network I/O.
- The transport shares one bounded queue with the Drizzle and Prisma adapters.
- `shutdownStackNext()` flushes buffered spans and is safe to call more than
  once.
